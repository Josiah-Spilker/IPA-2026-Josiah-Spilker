Titel der Arbeit
Extension Dynamics CRM / MS Power Platform
Ausgangslage
Data quality plays a critical role in the effective use of Microsoft Dynamics 365 / Dataverse systems. One of the most common data quality issues is the occurrence of duplicate records, which can lead to inconsistencies, redundant data storage, and incorrect business decisions.

The standard duplicate detection functionality provided by Microsoft Dynamics 365 allows the identification of potential duplicates based on predefined rules. However, it offers only limited support for further processing of these duplicates. In particular, there is no efficient and user-friendly way to review multiple duplicate records simultaneously and perform a structured merge based on field-level decisions.

Within a customer project, an enhanced duplicate detection mechanism is being developed. This mechanism creates dedicated records whenever duplicates are identified. These records serve as containers and store references to all affected business records.

Based on this technical foundation, an extension is required to support users in processing these duplicates efficiently. The objective is to develop a Power Apps Component Framework (PCF) control that visualizes the detected duplicates and enables an improved multi-merge process directly within the Dynamics 365 user interface.

The solution targets multiple audiences: CRM end users such as sales representatives or data stewards who process duplicate records on a daily basis, as well as Technical Consultants who configure and deploy the solution within customer projects. Additionally, Sales teams benefit from a demonstrable, reusable component that can be presented to potential clients as part of a CRM data quality offering.
Detaillierte Aufgabenstellung
The objective of this Individual Practical Assignment (IPA) is to design and implement a PCF control that enhances the handling of duplicate records in a Dynamics 365 / Dataverse environment.

The intended users range from business users requiring an intuitive interface for day-to-day duplicate resolution, to Technical Consultants who integrate and adapt the solution across different customer environments. The goal is to provide a reusable, extensible tool that reduces the time and complexity involved in resolving duplicate records — improving overall data quality and serving as a showcase component in customer engagements.

Additionaly, a fundamental data structure to bind relevant records to shall be used as a basis for the in-development enhanced duplicate detection plugin and be designed and implemented within the context of this assignment.

The PCF control shall operate on records generated by the enhanced duplicate detection plugin. Each of these records contains references to multiple business records that have been identified as duplicates.

The component must provide a structured overview of all linked records and enable the user to compare their field values in a clear and intuitive manner. Based on this comparison, the user shall be able to select, for each relevant field, which value must be retained in the final merged record.

The merge process shall be performed in such a way that all selected values are written into a designated primary record. After successful completion of the merge operation, all remaining duplicate records shall be deactivated.

The implementation must ensure data consistency and provide appropriate error handling. Furthermore, the solution must be designed in a generic and extensible manner so that it can be reused for different tables within the Dataverse environment.

Task Description

As part of this IPA, a PCF control for model-driven applications in Microsoft Dynamics 365 / Dataverse will be developed, as well as a fundamental data structure that serves as the basis for the enhanced duplicate detection plugin. The duplicates will be assigned to a single record within this new structure, serving as a collection and processing point.

The control is embedded in the context of a duplicate detection result record and retrieves all related duplicate records via the Dataverse Web API. The retrieved data is then presented in a comparison-oriented layout.

The implementation must support at least the following Dataverse field types:
- Text
- Choice (Option Set)
- Lookup

The architecture of the solution must allow future extensions to additional tables and field types without significant changes to the core logic. Design decisions for the implementation have to be documented.

The merge logic must be implemented directly within the PCF control using Dataverse Web API calls. It must be ensured that the operation is executed reliably and consistently.

Deliverables

The following deliverables are required:

- A managed solution containing the developed PCF control and all required components, which can be imported into another Dynamics 365 / Dataverse environment without errors.
- A short technical documentation describing:
○ The purpose and functionality of the PCF control
○ Instructions for PCF configuration

Acceptance Criteria

The solution is considered successfully completed if the following criteria are met:
- A well designed data structure is available to demonstrate the new process
- All duplicate records linked to a duplicate detection result are correctly displayed.
- The user can select values per field from different duplicate records.
- The selected values are correctly written into the primary record.
- All non-primary duplicate records are deactivated after confirmation.
- The solution works for at least two standard tables (Accounts and Contacts).
○ The Account entity must be able to merge the fields "name", "address1_line1", "address1_postalcode"
○ The Contact entity must be able to merge the fields "emailaddress1", "parentcustomerid", "preferredcontactmethodcode"
- The solution must support merging up to five records
- The specified field types (Text, Choice, Lookup) are handled correctly.
- The exported solution can be imported into another environment without errors.
- The exported solution includes all required components
- The exported solution can be easily integrated into a Model Driven solution.
- The instruction manual enables setup in different environments.

Scope Exclusion

The following aspects are explicitly not part of this IPA:
- Full implementation of the duplicate detection logic within the designed structure.
- Processing and deactivation of the subentities of duplicates
- Replacement of the standard Dynamics 365 merge functionality.
- Support for all existing Dataverse field types.
- Support for fields not defined within the acceptance criteria
- Support for merging more than five records
- Fully automated merge processes without user interaction.
- Handling of fields with field level security enabled
- Integration of duplicate detection rules within the data structure
